# 研究筆記：施測者間信度（IAR）與評分者間信度（IRR）的差異

在研究設計中，**施測者間信度**（inter-administrator reliability, IAR）與**評分者間信度**（inter-rater reliability, IRR）都涉及「不同人之間的一致性」，但兩者檢驗的對象其實不同。前者關心的是**資料如何被引導與產生**，後者關心的是**既有資料如何被解讀與評分**。若未先釐清這一點，研究者很容易在設計信度檢驗時選錯方法，進而導致研究問題與分析策略不一致。

## 一句話先說結論

**IRR 檢驗的是「評分是否一致」，IAR 檢驗的是「施測是否一致」。**

## 一、兩者的核心差異是什麼？

### 1. 評分者間信度（IRR）

IRR 用來確認，多位評分者在面對**相同且固定的資料**時，是否會給出一致的判斷結果。這裡的重點不是資料怎麼來，而是評分者如何根據既定標準解讀資料。

換句話說，IRR 檢驗的是**評判過程的一致性**。常見情境包括：

- 多位專家評閱同一份測驗答案
- 多位評分者觀看同一段訪談錄影後進行評分
- 多位臨床人員根據同一份病歷資料進行等級判定

在這類設計中，受測者的表現通常被視為已經固定，研究者希望知道的是：**不同評分者是否能根據同一套標準，做出相近的判斷。**

### 2. 施測者間信度（IAR）

IAR 用來確認，不同施測者在執行**相同標準化程序**時，是否能使同一位受試者表現出一致的反應或得到相近的結果。

這裡的焦點不只是結果的判讀，而是資料產生之前的整個施測歷程。也就是說，IAR 檢驗的是**引導或誘發資料的過程是否穩定**。

常見情境包括：

- 不同訪談者對同一位個案進行標準化訪談
- 不同施測人員依照同一份程序手冊執行測驗
- 不同臨床工作者執行結構式評估後比較結果一致性

在這類設計中，受試者的反應不是預先固定的，而是會受到施測者的語氣、節奏、追問方式、程序遵循程度與互動風格影響。因此，IAR 特別適合用來檢驗**工具的標準化施測流程是否足夠穩健**。

## 二、比較表：IAR 與 IRR 的差異

| 比較面向 | 評分者間信度（IRR） | 施測者間信度（IAR） |
|---|---|---|
| 核心問題 | 不同評分者對同一份資料，是否給出一致分數 | 不同施測者執行同一程序時，是否得到一致結果 |
| 測量焦點 | 評判與解讀的一致性 | 施測與引導的一致性 |
| 資料狀態 | 資料通常已固定或凍結 | 資料在施測互動中動態生成 |
| 受測者角色 | 表現通常被視為既定 | 表現可能受施測者影響而改變 |
| 主要誤差來源 | 評分標準解讀不同、嚴苛度偏差、月暈效應等 | 程序執行差異、操作熟練度、追問方式、人際互動差異等 |
| 常見研究材料 | 錄音、錄影、答卷、病例摘要 | 現場施測、重複訪談、標準化測驗執行 |
| 典型目的 | 確認量表評分規則是否明確、客觀 | 確認施測流程是否標準化、可複製 |
| 常見設計 | 多位評分者對同一段錄影獨立評分 | 多位施測者分別對同一位受試者施測 |
| 適合回答的問題 | 「不同人看同一份資料，會不會打出不同分數？」 | 「不同人去施測，會不會導致受試者表現不同？」 |

## 三、誤差來源為什麼不同？

### IRR 的誤差來源：偏向「解讀上的偏差」

IRR 的主要誤差多半來自評分者本身。例如，不同評分者對量表定義的理解不一致，有些人習慣給高分，有些人較保守，或受到第一印象影響整體判斷。這類誤差的核心在於：**資料本身相同，但評分者的認知與判斷不同。**

### IAR 的誤差來源：偏向「程序與互動上的偏差」

IAR 的誤差則常來自施測歷程本身。例如，不同施測者是否完整遵守操作手冊、是否正確處理跳題規則、是否以一致語氣提問，甚至是否因過度同理或過度引導而影響受試者回答。這類誤差的核心在於：**資料尚未固定，施測方式本身就可能改變資料內容。**

## 四、放到訪談量表情境，應該選 IAR 還是 IRR？

訪談量表常是最容易混淆 IAR 與 IRR 的情境，因為研究者往往同時扮演兩種角色：

- 一方面是**施測者**，負責提問、引導與蒐集資料。
- 另一方面是**評分者**，需要根據受試者回應進行判分。

因此，應該選擇 IAR 或 IRR，關鍵不在於工具叫不叫「訪談量表」，而在於你的研究問題到底想驗證哪一個環節。

### 情境 A：你要檢驗的是「評分標準是否清楚」

若你的主要疑問是：同樣聽完一段訪談內容後，不同專家會不會因為量表定義不夠明確，而出現評分落差，那麼你要優先檢驗的是 **IRR**。

#### 建議設計

1. 由一位訪談者完成訪談。
2. 將訪談歷程錄音或錄影。
3. 讓兩位或多位評分者觀看同一份錄影資料。
4. 各自獨立使用量表進行評分。

#### 為什麼這樣做？

因為這種設計把受試者的表現「固定下來」，排除了不同訪談互動所造成的差異，能更純粹地檢驗評分標準本身是否足夠一致。若工具涉及複雜的主觀判斷或定性解讀，這一步尤其重要。

### 情境 B：你要檢驗的是「訪談流程是否標準化」

若你的主要疑問是：換一位訪談者來問同樣的問題，受試者會不會因為語氣、追問方式或流程掌握不同，而產生不一樣的回答，那麼你要檢驗的是 **IAR**。

#### 建議設計

1. 安排兩位不同訪談者。
2. 在適當且不宜過長的時間間隔內。
3. 分別對同一位受試者執行相同訪談。
4. 比較兩次所得結果的一致程度。

#### 為什麼這樣做？

因為這能直接檢驗整個施測歷程是否具備足夠的標準化程度。若 IAR 高，代表只要接受適當訓練，不同施測者都能以相近方式引導出一致結果。對精神科、心理學或其他高度依賴標準化訪談的工具而言，這一點尤其重要。

## 五、研究設計上的實務建議

若你的工具仍在發展初期，而且評分高度依賴專家主觀判斷，通常建議**先建立 IRR，再考慮 IAR**。

原因很簡單。如果連相同資料的評分都無法一致，就很難判斷後續現場施測結果的不一致，到底是來自施測流程，還是來自評分規則本身。換句話說，**IRR 常是確認工具評分規則是否穩定的第一步**。

等到評分規則較為清楚、評分者訓練也較成熟後，若研究者仍擔心不同訪談者在現場操作時會影響受試者反應，再進一步評估 IAR，會更有助於釐清整體工具的信度結構。

## 六、總結

IAR 與 IRR 雖然都在處理「不同人之間的一致性」，但兩者處理的不是同一層次的問題。IRR 關注的是**資料已固定之後，判讀是否一致**；IAR 關注的是**資料尚在產生過程中，施測是否一致**。對訪談型工具而言，研究者要先問自己：我現在最想確認的，是「怎麼評分」的問題，還是「怎麼施測」的問題。這個判斷，會直接決定你的研究設計、資料蒐集方式，以及後續信度分析的解釋方向。

## 延伸思考

若你的工具同時包含訪談與評分兩個高度仰賴人員判斷的階段，其實可以把 IAR 與 IRR 視為兩個互補的信度面向，而不是二選一。前者回答施測流程是否穩定，後者回答評分標準是否清楚。兩者一起建立，通常更能完整說明工具在真實臨床或研究場域中的可用性。
